# bbport-kbm — клавиатура и мышь в стиле shadPS4 для Bloodborne PC

[English](README.md) · **Русский**

Альтернативная схема управления для нативного порта
[**Bloodborne PC / bbport**](https://github.com/deadinside28/bloodborne_pc) от deadinside28
(Windows-сборки — из Actions форка [DarkIzuku/bloodborne_pc](https://github.com/DarkIzuku/bloodborne_pc)).
Вы назначаете **клавиши на кнопки геймпада PS4** — точно как в настройке клавиатуры shadPS4, —
а не на список действий порта:

- **Конфиг shadPS4**: тот же формат `input_config` и те же имена клавиш; ваш `default.ini` /
  `CUSA03173.ini` из shadPS4 работает без изменений (импорт в один клик).
- **Любая клавиша или кнопка мыши на любую кнопку PS4**, комбинации (`lshift,leftbutton`),
  колесо и боковые кнопки, по две привязки на кнопку.
- **BloodborneControls.exe** — программа настройки: клик по полю, нажатие клавиши (русский / английский).
- **Камера мышью**: в v0.4 сохраняются родная камера и курсор в меню порта; иначе — модель
  «мышь → стик» из shadPS4.
- **Плавный поворот стика с клавиш** (без спотыкания, когда на бегу добавляешь A/D), диагонали
  «круг» или «квадрат».
- Настоящий геймпад продолжает работать, клавиатура и мышь добавляются к нему.

Файлы игры и файлы самого порта не входят в состав дополнения.

## Поддерживаемые сборки порта

| Сборка порта | Камера | Примечание |
|---|---|---|
| **v0.4** для Windows (PC-управление в лаунчере включено, по умолчанию) | родная камера мышью и курсор в меню порта | собственные привязки порта (*Controls*) отключаются, пока работает дополнение; клавиши и кнопки мыши — из `input_config` |
| **v0.4** с выключенным PC-управлением | мышь → правый стик (`mouse_to_joystick`) | всё управление — из `input_config` |
| **v0.1** («Bloodborne PC Offline v0.1») | мышь → правый стик | плюс исправление тачпада этой сборки (жесты, личные вещи) |

Дополнение находит нужное в `bb-probe.exe` порта по именам символов, поэтому само подстраивается
под сборку, в которую установлено, и пропускает то, чего в ней нет.

### Сравнение с собственным PC-управлением порта (v0.4)

| | PC-управление порта | bbport-kbm |
|---|---|---|
| Что назначается | 29 действий игры (атака, сильная атака + модификатор, …) | кнопки PS4 (R1, R2, ○, …), как на геймпаде |
| Настройка | в лаунчере, по действиям | клик и нажатие в BloodborneControls.exe или текстовый файл |
| Конфиг | `bbport.ini`, `bind.*` | `input_config` shadPS4 (переносится в shadPS4 и обратно) |
| Комбинации | только модификатор сильной атаки | любые 2–3 клавиши на любую кнопку |
| Камера мышью, курсор в меню | родные | родные (сохраняются) |

## Установка

1. Скачайте `bbport-kbm-x.y.z.zip` в разделе [Releases](../../releases).
2. Распакуйте **в папку Bloodborne PC** (где лежит `BloodborneLauncher.exe`).
3. Запустите `install-kbm.bat`. Оригинальная `out\SDL3.dll` сохранится как `out\SDL3_real.dll`.
4. Запустите `BloodborneControls.exe`, настройте клавиши (или «Импорт из shadPS4») и нажмите «Сохранить».
5. Запускайте игру из лаунчера как обычно.

**Удаление:** `uninstall-kbm.bat` возвращает оригинальную `SDL3.dll` (настройки остаются в
`input_config\`, собственные привязки порта снова работают). Отключить на один запуск:
переменная окружения `BB_KBM=0`.

## В игре

| Клавиша | Действие |
|---|---|
| **F7** | захватить / отпустить мышь (в режиме «мышь → стик») |
| **F8** | перечитать настройки (можно менять их в BloodborneControls.exe прямо во время игры) |
| **Insert** | меню порта; пока оно открыто, мышь свободна |

Мышь также отпускается, когда окно игры теряет фокус или открыто поле ввода текста.

## Настройки

`input_config\default.ini` и `input_config\global.ini` в папке Bloodborne PC, в
[формате shadPS4](https://github.com/shadps4-emu/shadPS4):

```ini
cross = e
r1 = leftbutton
r2 = lshift,leftbutton        # комбинация: обе удерживаются
pad_up = mousewheelup
axis_left_y_minus = w
leftjoystick_halfmode = tab
mouse_to_joystick = right
mouse_movement_params = 0.5, 1.0, 0.125   # deadzone offset, speed, speed offset
```

Дополнительные параметры (shadPS4 их игнорирует):

| Параметр | По умолчанию | Значение |
|---|---|---|
| `stick_smoothing_ms` | `70` | За сколько мс стик с клавиш поворачивается на 90°. `0` — мгновенно. Рекомендуется: 90 и 60 FPS — 40, 30 FPS — 70. |
| `stick_shape` | `circle` | `circle`: W+A наклоняет стик как настоящий палец (≈ 0.71, 0.71). `square`: в углы, как в shadPS4. |
| `mouse_poll_ms` | `33` | Период опроса мыши (в shadPS4 — 33 мс). |

`mouse_to_joystick` и `mouse_movement_params` действуют, только когда родная камера мышью порта
выключена; с ней чувствительность и инверсия задаются в лаунчере порта.
Горячие клавиши в `global.ini`: `hotkey_toggle_mouse_to_joystick` (F7), `hotkey_reload_inputs` (F8).
Клавиши определяются по физическому положению (скан-коды), раскладка (русская и т. п.) не важна.

### Зачем плавный поворот стика

С клавиш направление стика за один кадр прыгает на 45° (W → W+A). Палец так не умеет, и движок
FromSoftware может отвечать на такой скачок на бегу анимацией спотыкания (у меня это было в
Bloodborne и Dark Souls 3) — с одной стороны или с обеих, в зависимости от камеры.
Дополнение вместо скачка ведёт стик по краю (45° примерно за 35 мс по умолчанию).
Разворот W → S по-прежнему мгновенный, через центр.

### Тачпад: жесты и личные вещи

| Привязка | Что открывает |
|---|---|
| `touchpad_center`, `touchpad_left` | Жесты |
| `touchpad_right` | Личные вещи (Personal Effects) |

Игра принимает нажатие тачпада, только если касание выглядит как у DualShock 4: у каждого нажатия
новый id (1–127) и время удержания. Рантайм v0.1 отправляет id 0 и время 0, поэтому тачпад
игнорировался от любого источника (в порте это исправлено в 0.4,
[deadinside28/bloodborne_pc#48](https://github.com/deadinside28/bloodborne_pc/issues/48)). На v0.1
дополнение перехватывает чтение геймпада в рантайме и заполняет эти поля; в сборках с
исправлением оно ничего не делает.

### KeyTest.exe

Показывает каждое нажатие и отпускание клавиши со временем. Пригодится, чтобы проверить ghosting
клавиатуры (когда при нескольких зажатых клавишах некоторые «теряются»).

## Как это работает

`out\SDL3.dll` заменяется небольшой прослойкой. Все функции SDL она передаёт в оригинал
(`out\SDL3_real.dll`), кроме тех, через которые рантайм порта (`bb-probe.exe`) читает геймпад,
состояние клавиатуры, события и окно. Прослойка добавляет виртуальный геймпад «Keyboard & Mouse»,
работающий по вашим настройкам, и скрывает клавиатуру от собственной обработки клавиш рантайма
(жёсткая раскладка v0.1, `bind.*` v0.4). В v0.4 с PC-управлением нажатия кнопок мыши и колеса,
пока мышь захвачена, до рантайма не доходят (они ваши), а движение мыши и клики в меню доходят —
поэтому родная камера и курсор работают. Без родной камеры прослойка сама захватывает мышь
(относительный режим SDL) и превращает её движение в правый стик. Меню порта и поля ввода
находятся по символам рантайма; пока они открыты, мышь свободна. Лог: `logs\kbm-input.log`.

Файл `.def` прослойки генерируется из экспортов SDL3.dll самого порта (в v0.1 и v0.4 она одна и
та же), поэтому если обновление порта принесёт другую версию SDL3, дополнение нужно пересобрать.

## Сборка

Нужны Windows 10/11, Python 3 и `pip install ziglang` (компилятор C); компилятор C# из .NET
Framework 4 входит в Windows.

```bat
python build.py --bbport "D:\Games\Bloodborne PC"            :: собрать в dist\
python build.py --bbport "D:\Games\Bloodborne PC" --install  :: и установить
python build.py --bbport "D:\Games\Bloodborne PC" --zip      :: и упаковать zip для релиза
```

`--bbport` — папка Bloodborne PC (нужны экспорты её SDL3.dll).
